CAPRICORN // SETTINGS

Settings stay on this PC.

File tools exclude drive C. Installed apps may still run on C. File actions: list, read text, create folder/text, copy, rename/move on one drive, Recycle Bin. Window actions: focus, minimize, maximize, restore, close. Supply absolute paths.

Available actions: open installed apps by Start menu name, local drives and folders; add tasks; remember preferences. Computer tools also handle file actions outside C and app windows.

Sprite art & animation: Capri project by Lachy; artist private. Credits and license: THIRD_PARTY_NOTICES.md in the project folder.
